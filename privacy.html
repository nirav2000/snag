Snag privacy notice

Effective 27 September 2026.

Data used to provide Snag

Snag stores account identifiers, project/property details, snag records, comments, status history and media users choose to upload. Firebase provides authentication and project data storage. Cloudflare provides media storage and delivery. Stripe processes payments when billing is enabled; Snag does not store full card details.

Usage telemetry and App Monitor

Firebase usage telemetry and personalised App Monitor telemetry are enabled by default. They may record application usage, browser/device identifiers, session activity and authentication identity where available, for service operation, investigation and product improvement. Essential requests needed to authenticate, save, retrieve and secure a project operate independently. Where the service operator enables a user telemetry control, it is available in Settings.

Sharing

Project owners control invitations and can revoke access. Contractor access is restricted to authorised project membership and, on access-model-v2 projects, assigned/participating snags. New private media requires authenticated project access.

Export, retention and deletion

Project owners can export and delete projects from Account & billing. Account deletion removes accessible Snag account data, memberships and owned project data from the active application dataset. Infrastructure-provider backup/log retention may continue for limited periods.
